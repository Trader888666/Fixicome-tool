固定收益金流試算 加密打包器

在自己的電腦上設定密碼，產出可放上 GitHub Pages 的加密版 index.html。密碼不會傳到任何地方。工具版本：2026/10/28

請勿上傳或分享本打包器檔案。它含有未加密的完整工具與資料，只上傳它產生的 index.html。

建立加密檔

第一次使用，或工具資料更新後（例如新的報價檔、LTV 公告），用這裡重新產生。

    更改密碼

    選擇目前網站上的 index.html，輸入舊密碼與新密碼，產生新密碼版本。內容不變，只換密碼。

      放上 GitHub Pages

      1. 登入 github.com → 右上角「＋」→ New repository，名稱例如 fi-tool → Create repository。
      2. 在儲存庫頁面點 Add file → Upload files，上傳剛產生的 index.html → Commit changes。
      3. 第一次：Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、/ (root) → Save。
      4. 等 1～10 分鐘，網址為 https://你的帳號.github.io/fi-tool/。
      5. 更新資料或更改密碼時：重新上傳 index.html 覆蓋舊檔即可，網址不變。舊密碼於覆蓋後失效（已下載舊檔者除外）。
      6. 網址與密碼請分開傳送（例如網址用 email、密碼用電話）。
